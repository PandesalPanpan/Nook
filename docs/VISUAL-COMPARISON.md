Native screenshot density and usable window dimensions differ from the 375 px design fixture; logical spacing, typography, asset geometry and surface hierarchy are compared rather than OS clock pixels. Required text and action targets flow at 200% font size and narrow widths. Web Project and Note also have screenshots and passing interaction/geometry checks at 1024, 390 and 320 px. Widget rendering covers 20 size/font configurations under `artifacts/visual/widget-fonts`.

Accessibility adaptations are intentional: white text on brand-blue filled actions, light blue for ordinary text/field focus, dark text on orange/teal/yellow, stronger secondary text on elevated surfaces, visible keyboard focus, labelled icon actions and at least 44–48 dp native action targets. Decorative original markers have no redundant screen-reader description. No mascots, characters, gradients or illustrative substitutes were introduced.

The current native screenshot refresh and final regression result have been inspected: the full connected gate passes 49 executed tests, with eight configured-backend skips and no failures/errors; the post-gate production capture/Inbox refresh passes both tests. See `docs/VERIFICATION.md` for exact report names and counts. The named web production/source flows pass as part of all fourteen offline browser tests.
