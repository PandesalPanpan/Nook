# Nook 0.2.0

## Highlights

- Added optional Android update checks from public Nook GitHub Releases, with a quiet six-hour background schedule and a fresh manual check in Settings → About Nook.
- Added an inline update card, download progress, cancellation, retry, and Android's normal APK installer flow.
- Update downloads are checked against the release SHA-256, Android package and version, and the pinned Nook release certificate before Android is asked to install them.
- Added a permanent release signing identity and a tag-driven GitHub Actions release pipeline. Firebase client configuration is restored from an Actions secret for production builds.
- Existing local-first storage, Room/outbox sync, Firebase Auth/Firestore, widgets, reminders, capture, and offline use remain available independently of GitHub.

## First production install

This release is signed with Nook's permanent release certificate. A debug-signed installation cannot be upgraded in place to this certificate. If Android rejects installation over the existing debug build, export a Nook backup, uninstall that debug build once, and install this release. Later releases use the same certificate and install over the existing app.
