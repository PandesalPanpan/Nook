# Nook 0.2.3

The A1 dormouse is now the Android launcher icon, including an adaptive foreground/background and a simplified Android themed-icon layer. Nook's warm charcoal background keeps the artwork legible through circle and squircle masks.

The character is also visible beside the Android Today greeting, in the app's brand marker, beside the web Today heading, and in the web brand marker. The web production build includes a dormouse browser-tab favicon plus matching Apple touch and installable PWA icons.

This signed release uses the existing `app.nook` application ID and release certificate, with the next Android version code. It installs over Nook 0.2.2 through Nook's existing updater and leaves its local Room data intact.
